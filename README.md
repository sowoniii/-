# ✋ 손으로 놀자!

아이들이 카메라 앞에서 **손과 얼굴을 움직여** 화면과 노는 체험용 웹앱입니다.
설치 없이 브라우저에서 바로 동작하고, 카메라 영상은 기기 안에서만 처리됩니다 (어디에도 저장·전송하지 않음).

| | 놀이 | 이렇게 하면 | 이렇게 돼요 |
|---|---|---|---|
| 🫧 | 비눗방울 | 손바닥을 활짝 펴요 | 손바닥에서 비눗방울이 퐁퐁 나와요. 손가락으로 콕 찌르거나 꽉 잡으면 터져요 |
| 🌬️ | 입김 그림 | 화면에 대고 "후~" 불어요 | 창문처럼 김이 서려요. 손가락 하나를 펴서 그림을 그리면 닦여요 |
| 🐰 | 동물 귀 | 브이 ✌️ | 머리 위에 고양이·토끼 귀가 뿅! 한 번 더 브이 하면 다른 동물로 바뀌어요 |
| 👆 | 늘어나는 손가락 | 한 손 검지를 펴고, 다른 손으로 손가락 끝을 집어 당겨요 | 손가락이 고무줄처럼 쭈욱 늘어나요. 놓으면 띠용~ |
| ✊ | 말랑 화면 | 주먹을 꽉 쥐고 당기거나 돌려요 | 화면이 젤리처럼 늘어나고 일그러져요. 놓으면 출렁출렁 |

## 실행하기

필요한 것: 웹캠(가능하면 마이크도), 최신 크롬·엣지·사파리, [Node.js](https://nodejs.org) 18 이상.

```bash
npm install
npm start            # http://localhost:8080 을 브라우저에서 열기
```

카메라는 보안상 `https://` 주소나 `localhost` 에서만 켜집니다.
처음 열 때 카메라·마이크 사용을 **허용**해 주세요. 마이크가 없어도 입김 그림 놀이를 제외하면 모두 동작하고,
입김 그림도 입을 오므려 부는 입 모양을 카메라로 알아보거나, 잠시 뒤 자동으로 김이 서리게 해서 그림 그리기는 할 수 있습니다.

### 오프라인 전시 준비 (권장)

기본으로는 손 인식 라이브러리와 모델을 인터넷(CDN)에서 받아옵니다. 전시장처럼 인터넷이 불안정한 곳에서는 미리 내려받아 두세요.

```bash
npm install
npm run setup        # vendor/ 폴더에 MediaPipe 라이브러리와 손·얼굴 인식 모델(약 45MB)을 저장
npm start
```

`vendor/` 폴더가 있으면 앱이 자동으로 그것을 사용합니다. 이후에는 인터넷 없이 동작합니다
(제목 글꼴만 인터넷이 없으면 기본 글꼴로 보입니다).

## 전시(키오스크) 설정

주소 뒤에 옵션을 붙일 수 있습니다. 예: `http://localhost:8080/?kiosk&mode=bubbles&hands=4`

| 옵션 | 설명 |
|---|---|
| `kiosk` 또는 `autostart` | 시작 화면 없이 바로 카메라를 켜고 시작 |
| `mode=bubbles\|frost\|ears\|stretch\|warp` | 처음 시작할 놀이 |
| `hands=4` | 동시에 알아볼 손 개수 (1~6, 기본 4). 컴퓨터가 느리면 줄이세요 |
| `faces=3` | 동시에 알아볼 얼굴 개수 (1~4, 기본 3) |
| `cpu` | 그래픽카드(GPU) 대신 CPU 로 인식 (GPU 문제가 있을 때) |
| `mute` | 소리 끄고 시작 |
| `debug` | 손 뼈대·손 모양 이름·FPS 표시 |
| `sim` | 카메라 없이 마우스로 연습하는 모드 |

크롬 키오스크 실행 예: `chrome --kiosk --autoplay-policy=no-user-gesture-required "http://localhost:8080/?kiosk"`

### 조작

- 아래쪽 동그란 버튼을 눌러 놀이를 바꿉니다. 손으로만 체험할 때는 **검지로 버튼을 1.5초 가리키면** 선택됩니다.
- 키보드: `1`~`5` 놀이 바꾸기, `M` 소리 켜기/끄기, `D` 디버그 표시, `Esc` 처음 화면.
- 오른쪽 위 버튼: 처음 화면 🏠, 소리 🔊, 전체 화면 ⛶.

### 잘 되게 하는 팁

- 아이 상반신과 두 손이 화면에 다 들어오도록 카메라에서 1~2m 떨어져 서게 해 주세요.
- 밝은 조명이 좋고, 뒤에서 비추는 강한 빛(창문)은 피해 주세요.
- 입김 그림은 마이크가 아이 입 가까이(화면 아래쪽 등) 있을 때 가장 잘 반응합니다.

## 개발

```
index.html, styles.css       화면 뼈대와 디자인
src/main.js                  시작점: 카메라 → 인식 → 놀이 → 그리기 반복
src/core/                    공통 엔진
  tracker.js                 MediaPipe 손/얼굴 인식 (vendor/ → CDN 순서로 불러옴)
  gestures.js                손 모양 판별 (펼침/주먹/브이/가리킴/집기)
  handtracker.js             손 id 추적, 떨림 보정(One Euro), 손 모양 안정화
  facetracker.js             얼굴 위치·기울기·정수리·입김 입모양
  stage.js                   WebGL 무대: 말랑 격자 + 영상 조각 그리기
  mic.js, sound.js           입김 소리 감지, 효과음 합성
  sim.js, synth.js           카메라 없는 연습 모드 (가짜 손·얼굴)
src/modes/                   놀이 5가지 (만드는 법: src/modes/README.md)
src/ui/ui.js                 시작 화면, 버튼, 안내 문구
tests/                       단위 테스트 (npm test), 브라우저 자동 점검 (npm run e2e)
```

```bash
npm test             # 단위 테스트 (Node 내장 테스트) — 실제 사진에서 뽑은 손·얼굴 랜드마크 판별 포함
npm run e2e          # Playwright + Chromium 으로 모든 놀이를 연습 모드에서 자동 점검, 스크린샷은 test-results/
npm run e2e:real     # 실제 손·얼굴 사진을 가짜 카메라로 넣어 카메라→인식→놀이 전체 경로 점검 (ffmpeg, Pillow 필요)
npm run fixtures     # tests/fixtures/real-landmarks.json 다시 만들기
```

손 모양 판별은 MediaPipe 공식 테스트 사진(브이, 가리키기, 주먹, 엄지 척, 펼친 손)에서 뽑은 실제 랜드마크로도 검증합니다.

`npm run e2e` 는 Playwright 가 필요합니다 (`npm i -D playwright && npx playwright install chromium`).
